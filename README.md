# 🎬 agent-replay

> Time-travel for AI agents. Record a run, replay it move-by-move, share the link.

[![CI](https://img.shields.io/badge/CI-pending-yellow)]()
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![TypeScript](https://img.shields.io/badge/TypeScript-strict-blue)]()

When your AI agent does something weird, you ask: **"why did it do that?"**
Today the answer is *read the messy logs*. `agent-replay` gives you a
**timeline you can scrub** — every LLM call, every tool call, every thought,
reconstructable to any moment, and **shareable as a single file or link**.
